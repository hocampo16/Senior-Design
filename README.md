# Senior-Design

# Applied Multispectral Plant Phenotyping & Irrigation for Smart Precision Agriculture

## Overview  
This project focuses on developing a low-cost multispectral imaging system to assess plant hydration levels and optimize irrigation strategies. By leveraging **NDVI (Normalized Difference Vegetation Index) and NIR-IR sensors/cameras**, the system provides real-time plant phenotyping for **smart precision agriculture**.  

## Key Features  
- **Multispectral Imaging:** Captures plant reflectance data to assess hydration levels.  
- **NDVI Analysis:** Uses vegetation indices to determine plant health and water stress.  
- **Low-Cost Design:** Built with affordable NIR-IR sensors for accessible precision farming.  
- **Smart Irrigation Integration:** Potential for automated irrigation based on hydration insights.  

## Hardware & Software Requirements  
### Hardware  
- NIR-IR Camera/Sensor (Raspberry Pi Camera)  
- NDVI Filter (Red/NIR)  
- Microcontroller (Raspberry Pi 5)  
- LED Light Source for controlled imaging  

### Software  
- **Python** (core programming)  
- **Raspberry Pi OS**
